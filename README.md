# Sourdough Diary: the website

Static pages, served by GitHub Pages.

- `index.html`: the home page (the scroll story)
- `starter.html`, `baking.html`, `diary.html`, `learn.html`: feature pages
- `privacy.html`: privacy policy (English + Deutsch). App Store Connect points here.
- `support.html`: support page (English + Deutsch). App Store Connect points here.
- `assets/`: shared styles, script and images

When the app changes what it collects, `privacy.html` changes first. The App
Store version of the policy is the one people rely on, and a build must never
be ahead of it.

Edited in the app repo under `Launch/` and copied here. The feature pages are
generated by `Claude outputs/website-builder/pages.py`.
